 CoffeeHouse — Modern Coffee Shop Landing Page
A modern, responsive landing page for a coffee shop built with HTML, CSS and JavaScript.
This project is part of my front-end portfolio and demonstrates the ability to create clean, responsive and user-friendly interfaces.
 Live Preview
https://diachukmatviy.github.io/CoffeHouse⁠
 Overview
CoffeeHouse is a visually clean and modern landing page designed for small coffee businesses.
The website focuses on simplicity, accessibility and clear user interaction.
It includes key sections that every business website needs:
hero section with call-to-action
product/menu showcase
about section
contact information
 Tech Stack
HTML5 — semantic structure
CSS3 — layout, styling, responsive design
JavaScript (Vanilla) — interactivity and UI behavior
Git & GitHub — version control and deployment
 Features
Fully responsive design (mobile-first approach)
Smooth scrolling and reveal animations
Interactive navigation
Clean and modern UI
Reusable layout structure
Optimized for small business presentation
 Responsiveness
The layout is optimized for:
 Mobile devices
 Laptops
 Desktop screens
All elements adapt correctly to different screen sizes.
 Key Implementation Details
Structured layout using Flexbox

Scroll-based animations (JavaScript)

Simple and readable code organization
